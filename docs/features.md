# Product features (`@Features`)

Product features have stable, case-sensitive PascalCase `@FeatureName`
markers. Search the repository for a marker to find its BDD scenarios, unit
tests, and documentation. Every test names exactly one primary feature.

| Feature | What it covers |
| --- | --- |
| [@AIMealSuggestions](https://github.com/colinccook/planny-planny/search?q=%40AIMealSuggestions&type=code) | Building AI-ready meal suggestion prompts. |
| [@Authentication](https://github.com/colinccook/planny-planny/search?q=%40Authentication&type=code) | Registration, sign-in, sign-out, and protected routes. |
| [@ChatGPTPlugin](https://github.com/colinccook/planny-planny/search?q=%40ChatGPTPlugin&type=code) | The MCP plugin, OAuth, tools, and plugin information. |
| [@ClaudeIntegration](features/claude-integration.md) | Connecting the MCP server to Claude. |
| [@Headcounts](https://github.com/colinccook/planny-planny/search?q=%40Headcounts&type=code) | Household defaults and per-day adult, child, and visitor counts. |

`@ClaudeIntegration` has a dedicated feature page whose **Tests** link performs
the same repository lookup. Add a focused page under `docs/features/` when a
feature needs more explanation than this index provides.
